# PromiseGap — Synthetic Enterprise Contract Discrepancy Dataset

> **30 High-Stakes B2B Cross-Examination Scenarios Generated via Meta Muse Spark (muse-spark-1.3)**

This dataset provides gold-standard synthetic evaluation pairs designed to test automated contract cross-examination engines. Each scenario includes a full commercial proposal, a technical specification, verbatim quote extraction, 4-state formal discrepancy verdicts (`CONTRADICTORY`, `UNSUPPORTED`, `AMBIGUOUS`, `SUPPORTED`), and quantitative deal risk scoring.

## 🔬 Schema Structure

Each JSON file follows the standard evaluation schema:
- `proposal_document`: Persuasive commercial commitments, SLAs, and warranties.
- `technical_specification`: Concrete engineering architecture, operational runbooks, and constraints.
- `commitments`: Array of analyzed claims with exact verbatim quotes and 4-state verdicts.
- `deal_risk_score`: Quantitative risk gauge (0–100).
- `telemetry`: Meta Muse Spark model identifier, timestamp, total tokens, and reasoning tokens.
